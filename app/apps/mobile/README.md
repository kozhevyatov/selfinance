# Selfinance — мобильное приложение

Нативное приложение для Android и iOS на Expo (React Native). Работает с любым сервером Selfinance через его API: при первом запуске приложение спрашивает адрес сервера.

Общий код (суммы, даты, типы API) берётся из `../../packages/shared`, так же как в веб-версии. Мобильное приложение не входит в npm workspaces и в Docker-образ сервера (`app/.dockerignore`), у него свои `node_modules`.

## Что есть

Всё, что есть в веб-версии:

- подключение к своему серверу (http и https, домашняя сеть тоже), вход по email или телефону, токены в Keychain / Keystore;
- главная: свободные деньги и полоса капитала, «После планов» с расшифровкой, «Впереди» (регулярные платежи и планы), лимит месяца, итоги и график по дням, последние операции, куда ушли деньги, счета;
- операции: расход, доход, перевод, корректировка, перевод между бюджетами; регулярный платёж прямо из операции, оплата по напоминанию, покупка по плану; выражения в сумме (`350+120`);
- лента операций: месяц или всё время, тип, счёт, категория, поиск;
- статистика: неделя, месяц, год, произвольный период; итоги со сравнением, ожидаемый доход, графики по дням и за 12 месяцев, структура (бублик), капитал, фильтры;
- счета: создание и правка, кредитки и кредиты, сверка баланса, заморозка, разморозка, погашение, архив;
- регулярные платежи, планы, лимиты, категории (иконки, цвета, порядок, архив);
- бюджеты: общие бюджеты, участники и роли, приглашения;
- настройки: профиль, пароль, валюта, оформление (светлая, тёмная, как в системе), устройства; администрирование;
- работа без интернета: последние данные сохраняются на телефоне; операции, внесённые без связи, сразу видны в ленте и отправляются на сервер, когда связь появится;
- вход по ПИН-коду и Face ID / отпечатку, напоминания о регулярных платежах и лимите месяца (локальные уведомления), выбор даты в календаре, быстрые действия на иконке;
- подсказка об обновлении сервера внизу «Ещё», плашка приглашений в общий бюджет на всех экранах.

## Первый раз

```bash
cd app/apps/mobile
npm install
npx expo install --fix     # подогнать версии пакетов под SDK
npx eas-cli@latest init                   # создать проект на expo.dev (owner nskarl), запишет projectId в app.json
npx eas-cli@latest update:configure       # включить обновления «по воздуху» (запишет updates.url)
```

## Сборка

```bash
npm run build:apk          # Android: .apk, ссылка и QR-код для установки
npm run build:ios          # iOS: сборка для App Store / TestFlight
npm run submit:ios         # отправить последнюю iOS-сборку в App Store Connect (TestFlight)
npm run build:ios:preview  # iOS: установка по ссылке на зарегистрированные устройства (eas device:create)
```

Сертификаты и профили iOS EAS создаёт сам, достаточно войти под Apple ID разработчика, когда спросит.

## Обновление без пересборки

Если менялся только код на JS/TS (экраны, логика), а нативные пакеты и `app.json` не трогали:

```bash
npm run update
```

Приложение подхватит обновление при следующем запуске. Если добавлены нативные пакеты, нужна новая сборка, а `version` в `app.json` и `package.json` нужно поднять.
