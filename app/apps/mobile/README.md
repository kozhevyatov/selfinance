# Selfinance — мобильное приложение

Нативное приложение для Android и iOS на Expo (React Native). Работает с любым сервером Selfinance через его API: при первом запуске приложение спрашивает адрес сервера.

Общий код (суммы, даты, типы API) берётся из `../../packages/shared`, так же как в веб-версии. Мобильное приложение не входит в npm workspaces и в Docker-образ сервера (`app/.dockerignore`), у него свои `node_modules`.

## Что уже есть

- подключение к своему серверу (http и https, домашняя сеть тоже);
- вход по email или телефону, токены в Keychain / Keystore;
- главная: «В обороте / Заморожено / Всего», долг и кредитки, итоги месяца, последние операции, счета;
- добавление и редактирование операций: расход, доход, перевод, категории с подкатегориями, выражения в сумме (`350+120`), счёт, дата, комментарий, удаление;
- лента операций по дням: поиск по комментарию, фильтр по типу, подгрузка при прокрутке;
- переключение бюджетов, светлая и тёмная тема, обновление данных при возвращении в приложение.

Остальные разделы (статистика, счета, планы, регулярные платежи, лимиты, настройки) пока открываются в веб-версии: «Ещё» → «Открыть веб-версию».

## Первый раз

```bash
cd app/apps/mobile
npm install
npx expo install --fix     # подогнать версии пакетов под SDK
npx eas-cli@latest init                   # создать проект на expo.dev (owner nskarl), запишет projectId в app.json
npx eas-cli@latest update:configure       # включить обновления «по воздуху» (запишет updates.url)
```

## Сборка

```bash
npm run build:apk          # Android: .apk, ссылка и QR-код для установки
npm run build:ios          # iOS: сборка для App Store / TestFlight
npm run submit:ios         # отправить последнюю iOS-сборку в App Store Connect (TestFlight)
npm run build:ios:preview  # iOS: установка по ссылке на зарегистрированные устройства (eas device:create)
```

Сертификаты и профили iOS EAS создаёт сам, достаточно войти под Apple ID разработчика, когда спросит.

## Обновление без пересборки

Если менялся только код на JS/TS (экраны, логика), а нативные пакеты и `app.json` не трогали:

```bash
npm run update
```

Приложение подхватит обновление при следующем запуске. Если добавлены нативные пакеты, нужна новая сборка, а `version` в `app.json` и `package.json` нужно поднять.

## Разработка
